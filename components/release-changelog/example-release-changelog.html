🚀 Release Changelog Component

A self-contained web component for displaying release changelogs

Example 1: Loading from External JSON

Usage: The component loads data from an external JSON file using the src attribute.
View Code
<release-changelog src="sample-changelog.json" items-per-page="3"></release-changelog> <script type="module" src="./release-changelog.js"></script>

Example 2: Inline JSON Data

Usage: You can pass JSON data directly via the data attribute.
View Code
<release-changelog data='{"meta": {...}, "items": [...]}'></release-changelog>

Example 3: Programmatic API

Usage: Control the component using JavaScript with the setData() method.

Try It Out:

View Code
const changelog = document.getElementById('changelog3'); changelog.setData({ meta: { title: "My Changelog", description: "Dynamically loaded data" }, items: [ { version: "1.0.0", date: "2024-01-01", title: "Initial Release", changes: ["First feature", "Second feature"] } ] });

📚 Documentation

Attributes

  • src - URL to external JSON file
  • data - Inline JSON string with changelog data
  • items-per-page - Number of items per page (default: 5)

Features

  • ✅ Single-file web component (no dependencies)
  • ✅ Automatic pagination for large changelogs
  • ✅ Auto-fill missing properties from meta defaults
  • ✅ Responsive design with shadow DOM
  • ✅ Programmatic API with setData() method
  • ✅ Support for external JSON or inline data
